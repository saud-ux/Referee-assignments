# مكتب التكليفات — نظام ترشيح حكام تنس الطاولة

نظام يدير البطولات والحكّام، يرسل للحكم **تكليفاً على مستوى البطولة** (فترتها ومكانها) على واتساب بزرّي **أنا متوفّر** و**أعتذر**، ويُظهر رده مباشرة في اللوحة.

التكليف على مستوى البطولة لا المباراة: يؤكّد الحكم توفّره للحضور خلال فترة البطولة، ويُحدَّد تكليفه اليومي على الأرض في التجمع.

## التشغيل خلال دقيقة

```bash
npm install
cp .env.example .env
npm start
```

ثم افتح `http://localhost:3000`

يعمل من أول مرة في **الوضع التجريبي**: كل شيء يشتغل، لكن الرسائل تُطبع في الطرفية بدل إرسالها. تقدر تسجّل رد الحكم يدوياً من اللوحة لاختبار المسار كاملاً قبل ربط واتساب.

## التخزين

- بدون إعداد: ملف محلي في `data/db.json`
- مع مفتاح خدمة في `FIREBASE_SERVICE_ACCOUNT`: ينتقل تلقائياً إلى Firestore بنفس الواجهة، بدون تغيير أي سطر آخر

هذا يخليك تربطه لاحقاً بقاعدة بيانات نظام الشاشة الحالي بمجرد إضافة المفتاح.

## ربط واتساب

### 1. الحساب
- أنشئ حساب مطوّر في ميتا، وأضف منتج واتساب إلى تطبيق جديد
- سجّل رقم جوال **غير مستخدم حالياً في واتساب**
- بدون توثيق تجاري: 250 مستلم مختلف كل 24 ساعة، وهذا يكفي بطولة كاملة

### 2. القالب
سجّل قالباً باسم `referee_availability_ar`، اللغة العربية، الفئة **منفعة** (لا تختر تسويق، السعر يتضاعف):

```
السلام عليكم
زميلي الحكم/ {{1}}
تم ترشيحك للمشاركة في تحكيم {{2}}

الفترة: {{3}}
المكان: {{4}}

يُحدَّد تكليفك اليومي في التجمع. نأمل تأكيد توفّرك عبر أحد الخيارين أدناه.
```

مع زرّي رد سريع:
- `أنا متوفّر`
- `أعتذر`

الترتيب مهم: الزر الأول هو تأكيد التوفّر والثاني هو الاعتذار.

### 3. الويبهوك
في إعدادات واتساب داخل تطبيق ميتا:
- الرابط: `https://نطاقك/webhook`
- كلمة التحقق: نفس قيمة `WHATSAPP_VERIFY_TOKEN`
- فعّل الاشتراك في حقل `messages`

### 4. المتغيرات
املأ `WHATSAPP_TOKEN` و`WHATSAPP_PHONE_ID` و`WHATSAPP_APP_SECRET` في ملف `.env`، وأعد التشغيل. الشريط العلوي راح يتغير من "وضع تجريبي" إلى "واتساب مفعّل".

## النشر

الخادم يحتاج استضافة دائمة ليستقبل الويبهوك — منصة Render مناسبة:
- أمر التثبيت: `npm install`
- أمر التشغيل: `npm start`
- أضف متغيرات البيئة من لوحة المنصة

انتبه: على الخطة المجانية القرص مؤقت، فاستخدم Firestore قبل النشر الفعلي.

## التكلفة المتوقعة

| البند | التكلفة |
|---|---|
| رسالة التكليف الواحدة | ≈ 0.04 ريال |
| رد الحكم بالقبول أو الاعتذار | مجاني |
| رسالة التأكيد بعد رده | مجانية (داخل 24 ساعة) |
| اشتراك شهري | لا يوجد |

بطولة فيها 300 تكليف ≈ 12 ريال.

## بنية المشروع

```
server.js            نقطة التشغيل
src/store.js         طبقة التخزين (ملف محلي أو Firestore)
src/whatsapp.js      الإرسال، التحقق من التوقيع، قراءة ردود الأزرار
src/routes.js        واجهة البيانات والويبهوك
public/              لوحة التحكم بالعربية
```

## رابط قروب البطولة

لكل بطولة حقل اختياري **رابط قروب واتساب**. يُضاف عند إنشاء البطولة، أو لاحقاً من زر **رابط القروب** فوق اللوحة. عندما يقبل الحكم التكليف يظهر له زر **انضم لقروب البطولة** في صفحة الرد ليدخل قروب واتساب الخاص بالبطولة. تُقبل روابط `http/https` فقط.

## الحالات

`pending` قيد الإرسال · `sent` بانتظار الرد · `accepted` متوفّر · `declined` اعتذر · `expired` انتهت المهلة · `cancelled` ملغى · `failed` فشل الإرسال

## الخطوة التالية المقترحة

1. مهلة رد تلقائية: إذا ما رد الحكم خلال ساعتين، يتحول التكليف إلى `expired` وينبّه أبوك
2. تنبيه لأبوك على واتساب عند كل رد بدل متابعة اللوحة
3. تكليف جماعي: اختيار عدة مباريات وتوزيعها دفعة واحدة
4. استيراد جدول البطولة من ملف بدل الإدخال اليدوي
5. سجل تكاليف كل حكم لحساب المستحقات
